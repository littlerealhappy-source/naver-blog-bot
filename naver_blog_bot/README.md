# Naver 블로그 자동 발행 봇 (3단계: Playwright 자동화)

## 사용 순서

1. 가상환경 활성화
   ```
   venv\Scripts\activate
   ```

2. 최초 1회, 로그인 세션 저장 (아이디/비번은 브라우저 창에서 직접 입력)
   ```
   python login_setup.py
   ```
   `naver_session.json` 파일이 생성됩니다. **이 파일은 로그인 세션 쿠키를
   담고 있으므로 절대 깃허브 등에 올리지 마세요.**

3. 발행 스크립트 실행 (처음엔 반드시 publish=False 로 임시저장까지만 테스트)
   ```
   python publisher.py
   ```

## 알아둘 점

- `blog_id`는 본인 블로그 주소의 `blog.naver.com/{여기}` 부분입니다.
- 스마트에디터 셀렉터는 네이버 업데이트로 언제든 바뀔 수 있습니다.
  오류가 나면 `error_screenshot.png` 를 확인하고 `publisher.py` 안의
  셀렉터를 실제 화면 구조에 맞게 보정하세요.
- 세션이 만료되면(며칠~몇 주 후) `login_setup.py`를 다시 실행하세요.
- 짧은 간격으로 반복 발행하면 네이버 어뷰징 탐지에 걸릴 수 있습니다.
  실사용 시 발행 간격에 랜덤 딜레이를 두는 것을 권장합니다.
- 캡차가 뜨면 자동으로 우회하지 않습니다. headless=False 상태로 직접
  처리해주세요.
